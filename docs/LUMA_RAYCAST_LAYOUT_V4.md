# Luma Raycast UI V4

## 原因和目标

2026-10-16 用户对 V3 的真实截图反馈：虽然有圆角，但视觉与参考 Raycast 差距仍然明显，具体体现在窄窗口、竖向双行密集列表、五个行内操作按钮，以及杂乱的排序/快捷键/清理底栏。因此 V4 不再调色，而是独立重排搜索启动器。

## 设计决定

- 宽度由 760 调为 980 逻辑像素，窗口由内容高度控制，Win10 圆角与 Acrylic 代码沿用 V3。
- 搜索栏高度增加约 14px，与结果区分组行建立明确层级。
- 非首页输入查询时，出现“搜索结果”组名和结果数量，数据绑定自 ListView。
- 结果每行改为 **文件图标｜主标题｜次级路径｜日期** 单行。标题可伸缩，路径自行省略、保留右侧时间。修复了第一次编译后 112.tpl 名称意外截断的问题。
- 行内原来的“打开文件夹、终端、复制、路径、删除”等五六个图标不再常驻，也不在当前行弹出。保留右键、Shift+F10，并在鼠标悬停行时出现单个更多操作按钮，调用现有 ContextMenu；文件操作逻辑和删除确认流程仍使用原实现。
- 底部不再渲染整行旧快捷键：改为左侧极简 Luma 标识 + 可点击循环的当前排序选项，中间状态文本，右侧“打开 Enter / 操作 Shift+F10”提示与帮助入口。
- 清除历史仍保留双击确认，按钮仅在鼠标位于底栏时展示。
- 本次仅改 Main、SearchBar、ScopeTabs、ResultRow、Footer 五个 QML 文件；不修改 C++ 搜索/服务代码。

## 回归与注意事项

- 不修改正式 `main`、v0.8.0 Release 或当前已安装的 `C:\Program Files\Luma`。
- 源代码分支：`ui/raycast-layout-v4`，在 `ui/luma-glass-v3` 基础上继续。
- 视觉截图使用隔离配置 `D:\Luma-Toolchain\SmokeProfile` 和 `--query 112` 取得，窗口实际为 980×660。
- 后续视觉验证仍要由用户体验，尤其是不同缩放/DPI、文件类型、任务栏内搜索框和应用主列表。
