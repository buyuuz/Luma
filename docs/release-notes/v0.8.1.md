# Luma v0.8.1 — Raycast V7

V7 搜索窗口现已成为 Luma 的维护基线。该版基于 WinShun 0.8.0 的搜索与索引实现；上游 WinShun 0.9.0 尚未并入，请勿用上游安装包覆盖 Luma。

## 新功能 · What's new

- 🎨 **Raycast 风格搜索界面**：深灰浮动面板、单行结果布局、快捷键操作入口和简洁底栏。
- 🟠 **Windows 10 平滑圆角**：Qt 逐像素 alpha 主窗口，28px 外圆角，避免旧版 Win32 硬裁切的四角痕迹。
- 🔠 **优化显示比例**：930px 窗口、放大搜索文字与文件名、缩小无效留白和结果行间距。
- 🧩 **保留既有搜索能力**：NTFS 索引、文件内容、插件、MCP 与原有快捷键逻辑不变。
- 🔄 **独立上游更新流程**：新增安全检查脚本和维护指南，上游代码只通过人工审核与测试后合并。

## Compatibility and notes

- Windows 10/11 x64，Qt 6.12 / MSVC 测试环境。
- 保留独立 Luma AppId、Windows 服务、数据目录和 MIT 原作者署名。
- Luma 内的检查更新仅访问 `buyuuz/Luma`，不会静默自动安装。
- 如需回退，旧版本 `v0.8.0` 安装包仍在本仓库 Releases。升级前建议备份重要设置；不要直接删除索引数据。
